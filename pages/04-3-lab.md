# 04-3. [종합 실습 Lab] 보고 듣는 양방향 음성 대화 루프 완성

음성을 입력받아 텍스트로 바꾸는 **STT 모듈(`04-1`)**, 지능형 상담과 대처법을 도출하는 **의료 파이프라인(`05-4`)**, 그리고 결과를 다시 따뜻한 음성으로 말해주는 **TTS 모듈(`04-2`)**을 하나로 결합하여, 스마트폰을 귀에 대고 의사와 직접 통화하듯 자연스럽게 대화하는 **완전한 양방향 보이스 루프(Voice Loop)**를 완성합니다.

---

## 1. 🎯 학습 목표
1. [음성 녹음] → [STT] → [의료 LLM/응급 감지] → [TTS] → [음성 재생]으로 이어지는 5단계 풀-파이프라인을 구축합니다.
2. 마이크 입력이 없거나 잡음만 발생했을 때의 예외 분기를 매끄럽게 처리합니다.
3. 음성 파일의 라이프사이클(생성, 사용, 소멸)을 관리하여 디스크 용량 낭비를 통제합니다.

---

## 2. 💡 핵심 개념

### ① 양방향 음성 대화 루프 (Bidirectional Voice Loop)

```text
[환자의 다급한 음성 입력]
          │
          ▼
┌──────────────────────────────────────────────┐
│ 1단계: speech_to_text() (Groq Whisper)       │ ──► "어지럽고 토할 것 같아요"
└──────────────────────────────────────────────┘
          │
          ▼
┌──────────────────────────────────────────────┐
│ 2단계: run_smart119_pipeline() (응급/RAG/LLM)│ ──► [의학 분석 및 대처 지침 수립]
└──────────────────────────────────────────────┘
          │
          ├─► 화면 렌더링용: 전체 텍스트 + 면책 고지
          ▼
┌──────────────────────────────────────────────┐
│ 3단계: text_to_speech() (gTTS 엔진)          │ ──► 순수 핵심 조언만 MP3로 합성
└──────────────────────────────────────────────┘
          │
          ▼
[스마트폰 스피커: AI 간호사 음성 즉각 재생]
```

## 4. 💻 단계별 실습 코드

```python
"""
파일명: voice_conversation_lab.py
기능: 음성 입력부터 최종 음성 출력까지의 양방향 풀-루프(Voice Loop) 종합 실습
"""

import os
from typing import Dict, Any
from speech_to_text import speech_to_text
from text_to_speech import text_to_speech
from integrated_medical_pipeline import run_smart119_pipeline


def handle_full_voice_consultation(incoming_audio_path: str) -> Dict[str, Any]:
    """
    환자의 음성 녹음 파일을 전달받아 전체 상담 루프를 거친 후 화면 텍스트와 응답 음성 파일 경로를 반환합니다.
    """
    # [1단계] 음성 인식 (STT)
    print("\n[단계 1/3] 목소리를 텍스트로 인식 중...")
    user_transcript = speech_to_text(incoming_audio_path)

    if not user_transcript:
        fallback_msg = "음성이 감지되지 않았습니다. 마이크를 켜고 다시 말씀해 주세요."
        fallback_audio = text_to_speech(fallback_msg)
        return {
            "user_text": "(음성 없음)",
            "bot_display_text": fallback_msg,
            "bot_audio_path": fallback_audio,
            "is_emergency": False
        }

    # [2단계] 의료 파이프라인 추론 (응급 감지, RAG, 초고속 LLM)
    print(f"[단계 2/3] 환자 질문 분석 및 의학 지침 검색: \"{user_transcript}\"")
    consultation = run_smart119_pipeline(user_transcript)

    # [3단계] AI 답변 음성 합성 (TTS)
    print("[단계 3/3] AI 의학 상담 답변을 음성으로 합성 중...")
    out_audio_path = text_to_speech(consultation["speech_text"])

    return {
        "user_text": user_transcript,
        "bot_display_text": consultation["display_text"],
        "bot_audio_path": out_audio_path,
        "is_emergency": consultation["is_emergency"]
    }


# --- 종합 루프 시뮬레이션 ---
if __name__ == "__main__":
    print("=" * 65)
    print("스마트119 완전 양방향 음성 대화 루프 종합 가동")
    print("=" * 65)

    # 실제 오디오 파일이 없을 경우를 대비한 가상 시뮬레이션
    dummy_wav = "mock_patient_voice.wav"
    
    if not os.path.exists(dummy_wav):
        print("\n[안내] 실제 마이크 입력 대신 텍스트 파이프라인 결합 상태를 최종 점검합니다.")
        simulated_text = "손목을 심하게 삐었는데 찜질을 어떻게 해야 하나요?"
        pipeline_res = run_smart119_pipeline(simulated_text)
        sample_mp3 = text_to_speech(pipeline_res["speech_text"])
        print(f"👉 화면 출력 문구:\n{pipeline_res['display_text'][:100]}...")
        print(f"👉 생성된 음성 안내 파일: {sample_mp3}")
    else:
        loop_result = handle_full_voice_consultation(dummy_wav)
        print("\n🎉 양방향 음성 대화 처리 성공:")
        print(f"- 환자 발화: {loop_result['user_text']}")
        print(f"- 응급 플래그: {loop_result['is_emergency']}")
        print(f"- 오디오 파일: {loop_result['bot_audio_path']}")
```
